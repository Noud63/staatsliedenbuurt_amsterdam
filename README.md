# Staatsliedenbuurt Amsterdam

A Next.js application dedicated to De Staatsliedenbuurt, a neighbourhood in the western part of Amsterdam.

## Key Components

- NextJS 15
- React 19
- NextAuth 5
- Next-intl
- SWR
- Tailwind 3
- MongoDB
- Cloudinary
